# Todo-list
A mini todo list developed using html, Css, Js 
the todo list has a input field, Button, List container that 
allows the users to write and add todo's into the list    

Features
input fields to enter the todos 
a list to add the todos 
button to mark tasks as completed and delete

Tech Stack
CSS, JavaScript
React (CDN)

 How to Run
Open the HTML file in a browser
The app runs directly
